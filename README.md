# MongoDB Practice – School Student Database

## About the Project

This project is a beginner-level MongoDB practice exercise designed to understand basic MongoDB commands and queries.

I created a `school` database and a `students` collection, inserted student details, and practised different MongoDB queries to retrieve specific information.

## Technologies Used

- MongoDB
- MongoDB Shell (mongosh)

## Database Details

**Database Name:** `school`

**Collection Name:** `students`

## Student Records

The collection contains five student documents with the following details:

## MongoDB Concepts Practiced

1. Creating a database using `use`.
2. Creating a collection using `createCollection()`.
3. Inserting multiple documents using `insertMany()`.
4. Retrieving all documents using `find()`.
5. Searching specific documents using `findOne()`.
6. Filtering documents using query conditions.
7. Using projection to display selected fields.
8. Hiding the `_id` field using `_id: 0`.

## Practice Questions

This project includes 15 MongoDB practice questions:

1. Find all students.
2. Find a student by name.
3. Find students enrolled in MERN Stack.
4. Find students whose age is 20.
5. Display only student names.
6. Display student names and courses.
7. Find students from Chennai.
8. Find Coimbatore students and display only their names.
9. Find one Java Full Stack student and display name and city.
10. Find all students and hide the `_id` field.
11. Find Chennai students and display name and course.
12. Find one student whose age is 21.
13. Display only student names and ages.
14. Find students enrolled in Python.
15. Display only course names.
